## ✨ Features

### 🛡️ Survival

- God Mode
- No Fall Damage
- Infinite Lives
- Freeze Timer

### 🎒 Movement

- Super Speed
- Teleport to Checkpoint
- Save / Load Position
- Slow Motion

---

## 📋 Requirements

- **OS** — Windows 10 / 11 x64
- **Game** — Where the Seeds Fall (latest Steam version)
- **Privileges** — Run as Administrator

---

## 🚀 Usage

1. **Launch the game** and load into a level.
2. **Run** `WhereTheSeedsFallTrainer.exe` as Administrator.
3. **Toggle features** in the GUI.

> 💡 If the trainer doesn't find the process or features don't work — the game was updated and offsets need refreshing.

## ⚠️ Disclaimer

For **single-player use only**. Back up your saves before use.
